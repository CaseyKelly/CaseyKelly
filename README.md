## Side projects

### 🎸 [FantasyPhish](https://github.com/CaseyKelly/fantasyphish)
A fantasy game for Phish fans. Pick 13 songs before each show, score points when the band plays them, and compete on the tour leaderboard. My most complete side project, built and shipped end to end.
**[Play it →](https://fantasyphish.com)**

### ♿ [Curbcut](https://github.com/CaseyKelly/Curbcut) · *early stage*
An AI agent that audits websites for accessibility issues (WCAG 2.1 AA) and proposes code fixes for a person to review. Named after the curb cut effect: changes made for accessibility tend to make things better for everyone. Building it now.
